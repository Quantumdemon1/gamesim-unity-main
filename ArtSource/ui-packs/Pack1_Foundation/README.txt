GameSim UI Visual Asset Pack

Target: Unity uGUI / URP 17.6

Recommended import settings:
Panels / Buttons / Chips
- Texture Type: Sprite (2D and UI)
- Sprite Mode: Single
- Mesh Type: Full Rect
- Filter: Bilinear
- Wrap: Clamp
- Alpha Is Transparency: On
- 9-slice borders: Panels 40 px, Buttons 32 px, Chips 28 px

Rings / Badges / Icons
- Sprite (2D and UI)
- Preserve Aspect: On
- Compression: None or High Quality
- Mip Maps: Off

Semantic colors
Accent #00BFFF = current focus / actionable
Gold #F6C344 = HOH / veto / achievement
Green #2ED47A = allied / positive
Pink #FF4F9A = romance / affection
Purple #8A5CF6 = strategy / secrets
Red #FF4D5E = danger / rivalry / nomination
Muted chrome should stay low-emphasis.

No text is baked into the reusable sprites; use TextMeshPro on top.
