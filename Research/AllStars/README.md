# All-Star research (stored for later integration)

The owner's decision of 22 Oct 2026 (`handoffs/OWNER-DECISIONS-2026-10-22.md`, section 1): the All-Star
research and campaign documents are stored in the repository now and integrated into the game later.
The repository is public, so this material, which is about real people, can be read by anyone.

- `ALL_STAR_STRATEGIC_CAMPAIGNS_CONTENT_BRIEF_20261021.md`: twelve All-Star strategic campaigns,
  designed but not integrated. Every situation and line in it is fiction set in the player's
  simulated season, not a claim about the real alumni.
- `ALL_STAR_STRATEGIC_CAMPAIGNS_DESIGN_REVIEW01_20261021.md`: the design review of that brief.
- The alumni research itself (`Assets/Plans/ALLSTAR-RESEARCH.md`: twelve alumni, directed pair priors
  and their public sources), the implementation plan and the gated characterization candidate
  (`AlumniCatalog`, `AlumniHistory`, `AlumniStrategy`, `AlumniVoice` and their tests) are on the branch
  `codex/allstar-characterization-20261012`, pushed as it was built rather than copied here.

The owner's 15 Oct decision still holds for the game: the All-Star player histories are to be rebuilt
to the project's rules (their own schema, NPC-to-NPC changes only through RelationshipLedger) after the
save work, not merged from that branch as is.
