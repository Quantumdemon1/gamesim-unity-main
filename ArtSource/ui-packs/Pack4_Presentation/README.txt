GameSim UI Asset Pack 4
===========================

Target:
- Unity uGUI
- URP 17.6

This pack focuses on:
- Diary Room
- Nomination / Veto / Eviction cinematic overlays
- Schedule / timeline UI
- Memory Wall
- Final Three / endgame
- Autonomous social / drama alerts
- Full-screen transitions
- Broadcast-style lower thirds and event overlays

Recommended Unity import settings:
- Texture Type: Sprite (2D and UI)
- Sprite Mode: Single
- Mesh Type: Full Rect
- Filter Mode: Bilinear
- Wrap Mode: Clamp
- Mip Maps: Off
- Alpha Is Transparency: On

Suggested 9-slice borders:
- Shells / large panels: 36–42 px
- Cards: 28–32 px
- Buttons: 28–32 px
- Tags / small chips: 20–24 px

Theme:
- Cyan = active / focus / current action
- Gold = power / HOH / Veto / winner
- Green = positive / ally
- Pink = romance
- Purple = strategy / diary / secrets
- Red = danger / nomination / eviction / drama
- Resting chrome stays muted

Use TMP for all text, names, labels, votes, weeks, days, and dynamic state.
