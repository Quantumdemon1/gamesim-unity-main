GameSim UI Asset Pack 3
===========================

Target:
- Unity uGUI
- URP 17.6
- Continues the visual language from GameSim UI Asset Packs 1 and 2

This pack focuses on:
1) Main Menu + Save Slots
2) Houseguest Dossier + Notebook Intelligence
3) Competition-specific HUD
4) Weekly Recap
5) Finale / Jury presentation

Recommended Unity import settings:
- Texture Type: Sprite (2D and UI)
- Sprite Mode: Single
- Mesh Type: Full Rect
- Filter Mode: Bilinear
- Wrap Mode: Clamp
- Mip Maps: Off
- Alpha Is Transparency: On
- Compression: None / High Quality

Suggested 9-slice borders:
- Shells / large panels: 36–42 px
- Cards: 28–32 px
- Buttons: 28–32 px
- Tags / pills: 20–24 px

Semantic color rules:
- Cyan / Accent = current focus, current selection, actionable
- Gold = HOH, Veto, power, winner, major achievement
- Green = ally / positive relationship
- Pink = romance / affection
- Purple = secrets / strategy / jury-context
- Red = danger / nomination / eviction / negative state
- Resting chrome remains muted

Use TextMeshPro for all dynamic copy, names, stats, week numbers and labels.
